# NRO AI Game Master

Original text MMORPG / AI Game Master backend inspired by classic Dragon Ball-style progression.

## Endpoints
- GET /health
- GET /api/status
- GET /api/players
- GET /api/world
- POST /api/admin/command
- POST /api/reset

## Admin commands
/start, /status, /list_players, /create_player, /delete_player, /give_item, /set_level, /set_stats, /add_skill, /spawn_boss, /spawn_mob, /event, /broadcast, /ban, /unban, /teleport, /set_map, /quest, /clan, /pvp, /tournament, /dragon_ball, /wish, /god_mode, /time, /weather, /save, /load, /reset_server.

This project intentionally does not include leaked/proprietary source code or game assets.
